# Banking Transaction Monitoring System

A portfolio project using **SQL, Python, and Power BI** to analyze banking transaction activity, monitor transaction channels and statuses, and review rule-flagged transactions.

## Project highlights
- 500 synthetic customer records and 10,000 synthetic transaction records.
- SQL schema with primary/foreign keys and analytical queries.
- Python data-quality checks, KPI summaries, and charts.
- Power BI dashboard build guide and DAX measures.
- Processed summary CSVs and a PDF project summary.

## Setup
1. Install Python 3.10+ and packages: `pandas`, `numpy`, `matplotlib`, `jupyter`, `nbformat`.
2. Run `pip install pandas numpy matplotlib jupyter nbformat`.
3. Run the SQL scripts in order in MySQL Workbench: `01_create_database.sql`, `02_create_tables.sql`.
4. Import `customers.csv` into `customers` and `transactions.csv` into `transactions` using MySQL Workbench's Table Data Import Wizard.
5. Run `sql/03_analysis_queries.sql`.
6. From the project root, run `python python/analysis.py`.
7. Open Power BI Desktop, load the raw CSV files, follow `powerbi/dashboard_build_guide.md`, add measures from `powerbi/dax_measures.txt`, and save your report as `powerbi/banking_transaction_dashboard.pbix`.

## Dashboard pages to build
- Executive Overview: KPI cards, monthly trend, channel value, transaction status, slicers.
- Risk Review: flagged transaction table, flagged counts by channel, date/channel filters.
- Customer & Merchant Insights: city and merchant-category analysis.

## Data and limitations
All data is **synthetic** and generated for demonstration. The `risk_flag` field uses simple illustrative rules (for example, high transaction amount) and is not a real fraud detection model. Do not describe this as production fraud detection or real bank experience.
